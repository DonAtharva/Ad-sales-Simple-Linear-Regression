# Ad-sales-Simple-Linear-Regression
This project uses Simple Linear Regression to analyze the relationship between advertising spend and sales performance. By training the model on sales and advertisement data, it predicts how changes in advertisement budgets influence sales.

# 📊 AdSales Predictor

## 📝 Description
AdSales Predictor is a **Simple Linear Regression** project that analyzes the relationship between **advertising spend** and **sales**.  
It predicts sales based on advertisement budgets, showing how marketing investments can impact business outcomes.  

This project demonstrates the basics of regression modeling with Python, including data preprocessing, training, evaluation, and visualization.  

---

## ⚙️ Features
- Load and preprocess sales & ads dataset  
- Train a **Simple Linear Regression** model using scikit-learn  
- Evaluate model performance (R² Score, RMSE)  
- Visualize regression line & predictions  

---

## 📊 Tech Stack
- **Python**  
- **Pandas** – data handling  
- **NumPy** – numerical operations  
- **Matplotlib / Seaborn** – data visualization  
- **Scikit-learn** – regression model
